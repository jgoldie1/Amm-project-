# Capture checklist
1. Record vertical 9:16 first for Reels/TikTok/Shorts; also capture 16:9 for TV/YouTube.
2. Use 5–8 second real gameplay shots, not static screenshots, wherever the current build supports them.
3. Prioritize the new West Side footage: Circle Park, Jefferson School, living school day, police/EMS/fire fleet, classroom, gym.
4. Capture TRYAMM LIVE/Network separately from StreetVerse so the app and game read as connected products, not one overloaded screen.
5. Show Meshy characters only when the real published rig is visibly better than the fallback.
6. Use captions on every spoken line.
7. Birthday spot can be energetic; Sabbath spot should avoid combat, sirens, monetization and aggressive CTA.
8. End both with the same four-note audio logo and `ENTER THE WORLD. LEAVE A LEGACY.`
