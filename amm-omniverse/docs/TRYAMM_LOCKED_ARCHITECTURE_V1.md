# TRYAMM Locked Architecture v1

Status: CANONICAL BUILD DIRECTION
Date locked: 2026-08-18

This document is the canonical architecture for TRYAMM. New work should extend this system instead of creating disconnected top-level products.

## Core user lifecycle

JOIN → DISCOVER → LEARN → CREATE → OWN → PUBLISH → PLAY/WATCH/LISTEN → BUILD COMMUNITY → EARN → GET PAID → ACHIEVE → GET RECOGNIZED → BUILD LEGACY.

## Primary navigation

HOME | PLAY | LIVE | CREATE | NEXUS

### HOME
Personalized dashboard with Continue, recommendations, Reels, creators, music, films/anime, games, LIVE, Academy, opportunities, wallet/passport status, notifications, and Stubbs AI.

### PLAY
Quantum Racer/GO SPEED, TRYAMM Hoops, Chainbreakers, future games, universal gamer profile, cloud progression, matchmaking, tournaments, spectator mode, leaderboards, anti-cheat, and accessibility controls.

### LIVE
Livestreaming, PK, creator broadcasts, concerts, premieres, faith events, game spectator streams, awards, moderation, captions/translation, and monetization where compliant.

### CREATE
Reels, songs, music videos, movies, realistic-character productions, cartoons, Black anime, podcasts, game moments, AR/VR/MR, holographic experiences, LIVE shows, and Omni Box packaging.

### NEXUS
Advanced ecosystem modules including Marketplace, Academy, creator services, jobs/opportunities, AI Café, security, accessibility, property, business tools, wallet/passport, rights, blockchain/advanced systems, and command-center functions.

## Stubbs AI intent layer

The first question is WHAT DO YOU WANT TO DO?

Stubbs AI identifies what the user already has, what is missing, and routes them to the right tools, Academy path, collaborators, opportunities, funding/support options, or production workflow.

## Creator Project model

All media outputs can belong to one Creator Project/IP property.

Example project:
Chainbreakers → movie → anime → soundtrack → Reels → game → merchandise → AR/VR/MR → LIVE premiere → Omni Box.

Rights metadata follows the project and its child assets.

## Creator Academy

Academy tracks include filmmaking, animation/anime, Reels, music/sound, holographic/immersive production, games, AI production, creator business, rights/licensing, faith media, and accessibility.

Learning should produce portfolio work, not only watched lessons.

## Story Economy

Reel → Story/episode → full experience → Omni Box → LIVE → game/world → commerce/community.

Creators can turn one property into multiple legitimate products and audience experiences.

## Omni Box

A shareable interactive package that can hold Reel, full video, episode, song, game level, comic, product, ticket, livestream, creator profile, AR/VR/MR experience, and bonus content.

## Immersive Music

One release may include stereo/spatial audio, cinematic music video, AR, VR, MR, holographic performance, interactive/game version, authorized remix/stems, LIVE, and Omni Box.

## Music infrastructure

HoloMusic + Set Apart Music + 64-Track Studio + Rights Registry + SplitPay + Royalty Ledger + external distribution partnerships.

Set Apart Music is a dedicated faith lane for Yahuah-centered music, Hebrew-faith rap, gospel, worship, testimony, spoken word, choir, and related immersive media.

Do not represent TRYAMM as a PRO equivalent to ASCAP/BMI until the necessary licensing, repertoire administration, royalty collection, legal, audit, and industry infrastructure exists.

## Charts and certifications

TRYAMM-owned charting must use verified, fraud-filtered metrics and published rules.

Certification ladder:
Gold → Platinum → Multi-Platinum → Diamond → Crown → Omniverse.

Omniverse can represent 1 billion verified qualifying engagements under published rules.

## Awards ecosystem

Flagship: TRYAMM Omniverse Awards.

Divisions include All American Marketplace Music Awards, Screen/Film Awards, Game Awards, Creator Awards, LIVE Awards, Immersive Awards, Academy Awards, Faith & Kingdom Awards, Set Apart Music Awards, Impact/Service Awards, and Hall of Fame.

Award systems may combine community voting, qualified Academy judging, and verified performance data depending on category. Buying votes is prohibited.

### Kenosha Stubbs Legacy Award

A living-honor award named for Kenosha Stubbs, a mother and licensed social worker, celebrating compassion, service, family impact, community care, strength, leadership, and generational legacy.

Kenosha Stubbs is the founding honoree. The award should not be reduced to a popularity contest.

## Multiple Algorithm Architecture

TRYAMM does not rely on one algorithm.

Specialized systems include Discovery, New Creator, Following, Local, Global, Set Apart/Faith, Music, Movies/Anime, Game Matchmaking, Opportunities, Talent Match, Academy, Marketplace, Awards eligibility/performance, Safety, Accessibility, and Stubbs AI intent routing.

## Algorithm Studio / My Algorithm

Users can create recommendation algorithms in three modes:
1. Basic sliders/toggles.
2. Visual weighted/rule blocks.
3. Plain-language creation through Stubbs AI.

Examples include New Creators First, Set Apart Rap Radar, Black Anime Rising, Chicago Indie Film Finder, Family Mode, Work Mode, Faith Mode, and Discovery Mode.

Algorithms can be saved, named, previewed, duplicated, remixed, shared, published, and followed.

Algorithm Curators can have profiles, followers, analytics, Academy credentials, Passport achievements, and appropriate monetization opportunities.

Custom algorithms only rank eligible content. They cannot disable moderation, age restrictions, blocked users, fraud protection, copyright enforcement, or geographic/legal restrictions.

Users must have controls such as Why This?, Show More, Show Less, Reset Recommendations, and Do Not Use This Activity.

## Fair discovery

Recommendation inventory should reserve meaningful exploration for new/unknown creators and avoid a winner-take-all feed. Creators should be discoverable through multiple independent lanes including Following, New, Local, Faith, Search, Music, Academy, opportunities, and direct sharing.

## Talent Exchange and Opportunities

Talent Exchange supports actors, voice actors, musicians, producers, engineers, animators, developers, writers, directors, editors, VFX, designers, translators, teachers, business professionals, and other verified skills.

Opportunities includes jobs, gigs, auditions, casting, collaborations, internships, grants, sponsorships, tournaments, creator competitions, and Academy opportunities.

## Rights Engine

Asset → owners → contractual splits → permitted uses → territory → term → revenue lanes → versioned agreements/signatures.

Changing future rights/splits creates a new agreement version rather than rewriting history.

## TRYAMM Money Engine

Use a sandbox-first double-entry ledger.

Distinct accounts include platform revenue, creator payable, master payable, publishing payable, collaborator payable, prize liabilities, tax payable, refund reserve, sponsor restricted, charity restricted, Kenosha Legacy restricted, ministry restricted, processing fees, operating reserve, and settlement cash.

Core rule: total debits = total credits before posting.

Creator earnings states:
pending settlement → cleared → held/payable → sent → paid/reversed.

Real payouts stay OFF until KYC/identity, tax onboarding, Stripe Connect, webhook verification, fraud controls, reconciliation, refunds/disputes, applicable legal/accounting review, and store/payment rules are satisfied.

Designated event logic remains separated from guaranteed player prizes. Existing business rule direction includes 20% Kenosha Legacy allocation and 10% ministry allocation for designated eligible event revenue according to the defined event accounting policy.

## All American Wallet

Wallet is the user-facing economic control center; Money Engine is the accounting authority.

Separated balance classes should include Creator Earnings, Marketplace/Seller Earnings, Prizes/Rewards, and Promotional/Game Credits. Game Credits must never look withdrawable.

Wallet timeline should explain source, amount, status, rights allocation, and payout state.

## All American Passport

The All American Passport is a TRYAMM membership/achievement credential, not a government passport.

It can contain Founding Player, Creator, Academy, Set Apart Artist, certifications, awards, community/service achievements, game achievements, events, and Hall of Fame/legacy credentials.

Government-issued passports, driver's licenses, mobile driver's licenses, and other credentials must always be identified as externally/government issued. TRYAMM may support verification/presentation through authorized partners and selective disclosure, but does not issue government identification.

## Tap / All American Card direction

NFC/QR creator/business identity can open profile, follow, listen, buy merchandise, Omni Box, tickets, receipts, and supported payments.

Actual payment-card issuance and regulated Tap-to-Pay acceptance require authorized issuing/payment partners.

## Reputation and Trust

Profiles should use verified work history, Academy credentials, completed projects, credits, service/reputation, and appropriate dispute data rather than easily purchased ratings.

## Accessibility

A single accessibility profile follows the user across TRYAMM. Support voice, captions/transcripts, screen readers, keyboard/switch input, scalable UI, reduced motion, high contrast, one-hand/adaptive controls, sign-language workflows where available, and accessible game controls.

## Safety / Moderation

Unified report/block/mute, moderation queues, anti-harassment, teen/adult protections where applicable, livestream tools, copyright/impersonation/likeness reporting, scam/fraud detection, appeals, and human escalation.

## Search / Notifications / Collaboration

Universal Search should span people, Reels, songs, movies/anime, games, LIVE, Omni Boxes, products, jobs, Academy, businesses, events, and worlds.

Universal Inbox should cover messages, comments, follows, collaborations, job/casting offers, sales, rights approvals, payouts, game/tournament notices, Academy progress, and award nominations.

Project collaboration rooms should support chat, files, tasks, scripts, storyboards, versions, contracts, rights/splits, approvals, and milestone payments.

## Analytics

Shared event vocabulary:
IMPRESSION → OPEN → WATCH/LISTEN → COMPLETE → FOLLOW → SAVE → SHARE → PLAY → PURCHASE → RETURN.

Creators see their funnel; TRYAMM sees platform health; charts/awards receive verified fraud-filtered metrics.

## Admin / Operating System

Internal command center should cover system health, LIVE rooms, reports, fraud, Money Engine reconciliation, payout holds, moderation, rights/copyright cases, support, game servers, and incidents.

Use feature flags with stages:
DEMO → INTERNAL → ALPHA → BETA → PUBLIC.

Keep REAL MONEY, REAL PAYOUTS, PRIZE COMPETITIONS, EXTERNAL DISTRIBUTION, GOVERNMENT CREDENTIALS, and regulated card/tap functionality behind separate gates.

## Launch philosophy

Freeze unnecessary new top-level features until horizontal systems are integrated.

The completion test:
A new person can join TRYAMM, understand what to do, discover something relevant, play/watch/listen/create, save progress, interact safely, return later, and—once regulated gates are enabled—earn and receive transparent payouts.

This document is the locked baseline. Future changes should be deliberate revisions to this architecture, not accidental drift.
