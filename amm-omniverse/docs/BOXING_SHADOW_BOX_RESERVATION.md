# Shadow Box — reserved for the future boxing game

Decision (2026-11-04): **Shadow Box belongs to the dedicated StreetVerse boxing game**. Do not add Shadow Box to the current StreetVerse open-world weapons wheel, inventories, mission rewards, or general combat until a separate boxing milestone is authorized.

## Boxing-game scope (future only)
- Purpose: shadow-boxing practice, boxing footwork, defensive moves, sparring drills, ring training, and accessible one-hand controls where appropriate.
- Use original boxing animations, calibrated hitboxes, stamina, round timers, safety systems and sports scoring; don't treat generic RPG gestures as boxing techniques.
- No item, weapon, money, equipment entitlement, or persistent training result should be fabricated.
- Keep boxing mode isolated from StreetVerse weapon loadouts and open-world crime missions.

## Current open-world priority
1. Connect existing RP action search and carousel to genuine BJ animation clips or visible rig-driven movements.
2. Report **played / unavailable** based on the character actually rendered, rather than reporting success from event dispatch.
3. Keep equipment ownership tied to existing game/server inventory authority; no free item grants.

This file records the feature reservation; it does not claim the boxing game is implemented.
