# BeautyVerse $0 development / no-surprise-cost guard

Status: planning and code-development policy, NOT an assertion that production operation has no fees.

## Approved now
- Modify existing repository and draft PR; no paid cloud accounts, hardware purchases, new domains, ads, or subscriptions.
- Keep booking, fashion, academy, CrossVerse and XR in local/preproduction demo mode.
- Reuse existing assets and basic web browser, gamepad and optional WebXR APIs.
- Use owner-approved free tools for client intake/availability preparation where their current terms allow it.
- Never submit real customer data into public demonstration routes.

## Explicit approval required before any spending
- Paid hosting, extra database capacity, email/SMS, AI inference credits or media transcoding.
- New domain or business mailbox subscriptions.
- Paid promotion, inventory, suppliers, shipment purchases and payment service upgrades.
- Any chargeable API endpoint or overage-based cloud plan.
- Sale of any regulated service or class before credential/approval validation.

## Commercial constraints
- Vercel Hobby is for personal non-commercial usage; it must not be used as the commercial live store.
- Free tiers may impose quotas and pause projects after inactivity. Confirm current vendor terms before activation.
- Stripe standard may have no monthly charge but still charges processing fees and possible other transaction fees.
- A true $0-upfront launch may use an existing lawfully commercial website/shop arrangement and manual confirmations with the owner's permission, without promising zero per-sale costs.

## Non-destructive activation gates
- Keep VITE_ENABLE_TAMPA_VOLCANO_BETA off by default.
- Keep app production main unchanged until CI/lint/build and scene fallback checks pass.
- Capture previous successful deployment, test rollback, and preserve player data.
- Owner authorizes services, merchant account, shop booking rules, and platform providers.
