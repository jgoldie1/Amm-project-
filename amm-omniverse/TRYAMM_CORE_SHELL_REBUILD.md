# TRYAMM Core Shell Rebuild

Status: LOCKED SPECIFICATION

## Goal
Rebuild the TRYAMM front-end shell without deleting or discarding existing systems. Preserve existing code, assets, business logic, worlds, media, education, AI, commerce, accessibility, supply-chain and creator systems, then reconnect them behind one coherent mobile-first shell.

## Core experience
TRYAMM Home -> Holographic Carousel -> destination -> experience -> back/home -> persistent state.

Primary gateways:
- Benny Stubbs AI — female AI guide and universal navigator
- StreetVerse
- Holoverse
- My World
- LIVE / PK / Debate
- Business PLO
- Africa Gateway
- Global Supply Chain
- All American Universities
- Marketplace
- Music / Radio
- Reels / Creator Tools
- Command Nexus

Primary quick actions:
- CREATE
- GO LIVE
- EARN
- EXPLORE
- SCAN

## Universal Scan Gateway
SCAN is a P0 gateway and must work inside and outside the app.

Flow:
Phone camera or external QR reader -> TRYAMM secure universal/deep link -> resolver -> installed app when available or web/PWA fallback -> Benny context -> destination/action.

Supported destination types include:
- Business Passport
- Business PLO profile
- Black Business Directory / Global Business Network
- Africa business or creator entry
- Global Supply Chain package/pallet/order record
- Marketplace product
- StreetVerse location
- Holoverse experience
- university/campus/program
- creator/profile/media/event

Use dynamic server-resolved QR identifiers so destinations can change without reprinting physical codes. Scanning never automatically authorizes payment, identity disclosure, signatures or sensitive actions; confirmation/authentication is required.

## Holographic shell
The approved visual direction is a dark cinematic holographic interface with a living carousel, immersive cards, central world/planet motif, clear utility bar and large touch-safe controls. Visual richness must not interfere with usability.

The home screen must surface major gateways directly. Do not bury StreetVerse, Benny, LIVE/PK/Debate, Holoverse, My World, Business PLO, Africa, Global Supply Chain or All American Universities in secondary menus.

## Mobile foundation P0
- Non-game pages must scroll vertically.
- Game controls/keypad only mount inside active gameplay.
- Home buttons must have real destinations or an explicit Coming Soon status.
- Back/Home/Exit Game must always be available.
- Deep links must resolve reliably.
- Session/profile/wallet/progress state must persist where appropriate.
- Accessibility and translation remain first-class.
- iPhone-sized layouts are primary test targets.

## Preservation rule
Before retiring any legacy component, classify it as KEEP / RECONNECT / REPAIR / REBUILD / ARCHIVE. Do not delete systems solely because the shell is changing.

Preserve and inventory at minimum:
- Benny / Stubbs AI
- StreetVerse and world assets
- Holoverse and Holographic Construct
- My World
- Live/PK/Debate
- Business PLO / Business Passport / directory/network
- Africa expansion systems
- Global Supply Chain
- All American Universities / School Network
- Marketplace and commerce
- Music/Radio/OTT/Reels/creator media
- payments, rewards, commissions and ledgers
- accessibility, moderation and translation
- Holo FON / connectivity work
- Command Nexus and advanced modules

## Definition of done for Core Shell 1.0
A mobile user can open TRYAMM, reach Home, scroll, open Benny, open LIVE, enter StreetVerse, access My World/Holoverse gateways, access Business/Africa/Supply Chain/Education gateways, scan a TRYAMM QR/deep link, return Home, and retain appropriate session state without controls blocking unrelated screens.
