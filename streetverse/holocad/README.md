# StreetVerse HoloCAD v24 pilot

Isolated safe building schema and validation for the fictional Taylor Street apartment. This does NOT replace existing gameplay, does not load untrusted scripts, and is not a production-ready CAD system. The full local v24 package with a browser viewer, mission and collision repairs is available separately in ChatGPT, but those wider files have **not** been committed to GitHub.

Run `node streetverse/holocad/tests.mjs`. Before any gameplay integration or deployment, inspect existing repository source, verify asset rights, and test BJ movement, driving, NPC, stairs/elevators and iPhone touch input. Do not merge untested game changes.
