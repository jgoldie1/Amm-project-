# TRYAMM Global Mobility Economic OS

This branch integrates the existing StreetVerse/TRYAMM architecture around four release-safe ideas:

1. Global mobility configurations for U.S. and African cities.
2. Business Passport, BPO/BPL, Omniverse Radio and Marketplace attribution.
3. Stubbs AI Command Agent read-only operational intelligence.
4. Internal append-only hash-chain records for verification and audit, while real money remains authoritative with regulated payment/banking providers.

Regulated exchange, securities, lending, tokenized equity and public crypto-market functions remain disabled unless and until appropriate legal/compliance requirements and licensed partners are in place.
