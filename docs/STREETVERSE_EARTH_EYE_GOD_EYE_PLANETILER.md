# TRYAMM Earth Eye / Mycelium / Cursor Construct / Time Machine
**Status:** Original lightweight proposal UI integrated into StreetVerse route. No imported God Eye code or raw geospatial surveillance feeds. **Not** a complete Earth replica, live globe, city engine or production map stack.

## Existing systems recovered (do not rebuild)
- **StreetVerse Chicago Three.js:** real browser 3D scene, basic collision, driving and NPC contracts. Mini-city collision in draft PR #736, not on main.
- **Cursor Construct** (`src/runtime/BennyCursorConstructBridge.ts`): catalog-backed inspect/explain/navigate/propose-build. Construct's production mutation is explicitly false and build proposals require approval.
- **Holographic Internet** (`src/runtime/HolographicInternetGoogloplexBridge.ts`): chooses metadata/thumbnail/mobile-3D/full-3D/immersive-XR delivery per capability.
- **Time Machine World Foundry** (`src/runtime/TimeMachineWorldFoundryRuntime.ts`): plans source-evidence-labeled reconstructions, original geometry recipes and server receipts with human review. It cannot alter the real past.
- **Holographic Gallery Center:** displays pre-approved product, art, music, Reels and asset studies. Not a volumetric physical hologram projector.
- **Mycelium** (draft PR #730): limited idempotent local simulation event graph; no server authoritative persistence yet.
- **CrossVerse city catalog** (draft PR #735): preview status beyond Chicago.
- **Aniyah Pay, Holo Credits, LIVE:** separate payment, virtual rewards and provider-gated live streams. Earth Eye cannot spend or transfer funds.

## Repository research
- **God's Eye View**: `https://github.com/bilawalsidhu/gods-eye-view`; **God's Eye**: `https://github.com/alkeincodes/gods-eye`. Inspiration: globe navigation, GIS overlays, source timestamp labels and historical replay; avoid copying unrelated intelligence, tracking, surveillance or military datasets. Audit source licenses, sub-dependencies, security, provider terms and accuracy before importing anything.
- **Planetiler:** `https://github.com/onthegomap/planetiler` — Apache-2.0 build tool for vector tiles from licensed OpenStreetMap extracts, output PMTiles/MBTiles. Run large geography exports in a *separate server/CI job*, never on the Chromebook or on player page load. Preserve OSM attribution and check data ODbL/share-alike obligations. Generated vector tiles are not a 3D city and cannot replace game collision, interiors, weather or character animation.
- **NASA GIBS** — optional licensed/attributed Earth imagery layer; satellite imagery is not real-time street video.
- **Open-Meteo production adapter** already present in TRYAMM — commercial license/provider verification required; static/mock weather must be marked simulated.

## MapLibre GL JS globe preview added (same PR)
- The existing application already depends on `maplibre-gl@6.7.0`; no additional paid renderer or map provider was installed.
- An optional user-opened `VIEW FIVE-CITY GLOBE` button lazy-loads the MapLibre WebGL context. ChromeOS may show an explicit text-selector fallback when additional graphics contexts are unavailable.
- Draws a *schematic* globe, GeoJSON city markers and the Chicago → Detroit → Tampa → Memphis → Atlanta route from the original fixed city catalog. It is not a satellite image, full Earth terrain model, licensed street basemap, travel simulation, or playable 3D scene.
- It makes **no external imagery requests**, GPS requests, payments, asset releases or player teleports. The map is destroyed when closed and opening is user-controlled.
- Add a reviewed/licensed regional tile provider later, e.g. Planetiler-generated PMTiles + a compatible PMTiles MapLibre source/protocol adapter. Test content rights, hosting, cache, network cost, attribution and performance before any switch.
- NASA GIBS may provide sourced/time-stamped imagery on an independent opt-in layer once its attribution/service details, tile projection, freshness and rates are verified; "live satellite video" must not be advertised without an actual current feed and permissions.
- Actual five-city transfer remains blocked until those city scenes exist, valid spawns are confirmed and Mycelium persistence/replay are authoritative. Plan is not evidence of transfer.

- Does the globe run smoothly on Chromebook and iPhone? Does the text fallback preserve all navigation?
- Can users distinguish a preview destination from a playable city, and simulated weather from a live observation?
- Are character likeness rights, archival reconstruction uncertainty and music/video licenses communicated clearly?
- Can a creator publish a 15-second replay and open a HoloVerse exhibit without losing game progress?
- Do customer inquiries, LIVE participation and subscriptions work with accessible UI and verified payment paths?
- Avoid marketing "full Earth clone", "photorealistic live satellites", "working five-city gameplay" until supported by actual data and multi-device tests.
