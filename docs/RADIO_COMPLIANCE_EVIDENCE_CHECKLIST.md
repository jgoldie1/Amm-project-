# Radio Compliance Evidence Checklist

Record a document link, owner, reviewer, date, expiration date, and status for every applicable item.

## Provider or license authority
- [ ] Carrier/private-network/provider agreement
- [ ] FCC license or spectrum-lease authority identified
- [ ] SAS/CBRS agreement if applicable
- [ ] Experimental license or STA if applicable
- [ ] Authorized frequencies, bandwidth, power, locations, and dates match the deployment

## Equipment authorization
- [ ] FCC IDs and grants collected
- [ ] Approved antennas, power, and host integrations confirmed
- [ ] RF exposure documentation collected
- [ ] Labels, notices, manuals, and change controls approved
- [ ] No unauthorized radios are marketed, imported, or deployed

## Engineering
- [ ] Frequency plan
- [ ] Coverage and interference study
- [ ] Link/path and rain-fade budget where applicable
- [ ] Antenna, EIRP, azimuth, height, and downtilt schedule
- [ ] Backhaul and redundancy design
- [ ] Emergency shutdown and rollback plan

## Site and structural
- [ ] Site-owner permission
- [ ] Structural engineer approval
- [ ] Zoning/building/electrical/fire approvals
- [ ] FCC antenna-structure/FAA review determination
- [ ] Grounding, lightning, backup power, and physical security acceptance

## Security and privacy
- [ ] Device identity and certificate plan
- [ ] Encryption and key rotation
- [ ] Anti-replay and group-administration controls
- [ ] Location consent and retention rules
- [ ] Vulnerability assessment and penetration test
- [ ] Incident response and breach-notification process

## Field tests
- [ ] Coverage and dead zones
- [ ] Throughput, latency, jitter, and loss
- [ ] Handover and fallback
- [ ] Chirp floor-control and emergency priority
- [ ] Accessibility tests
- [ ] RF exposure measurements
- [ ] Interference monitoring
- [ ] Power failure and recovery
- [ ] Security and replay tests
- [ ] Shutdown procedure drill

## Business and legal
- [ ] Insurance approval
- [ ] FCC counsel review
- [ ] Local legal/site review
- [ ] Vendor contracts and warranties
- [ ] Customer terms, privacy notices, and acceptable-use rules
- [ ] Claims review for 5G, 6G, 10 Gbps, millimeter wave, and terahertz

## Release decision
- [ ] All required evidence is current
- [ ] Critical findings are remediated and retested
- [ ] Named safety officer can suspend service
- [ ] Named release committee approves limited pilot
- [ ] Pilot exit criteria are satisfied
- [ ] Production authorization is signed
