# Jacobie Vision + PropertyVerse Figma Product Maps

These are first-class TRYAMM product families and inherit the shared Figma tokens, accessibility system, Creator/Business Passport patterns, ledgers and Command Nexus status language.

## Jacobie Vision — Cybersecurity

Purpose: defensive cybersecurity education, workforce development and security operations experiences connected to TRYAMM and StreetVerse.

### Required Figma pages and frames

- Jacobie Vision Home / Security Command Center
- Learner Passport and skills profile
- Cyber learning paths
- Defensive lab launcher
- CTF / green-team challenge board
- Hackathon and sponsor-prize board
- SOC training dashboard
- Threat-alert simulation
- Protected TRYAMM asset inventory
- Incident-response simulation
- Security score / readiness report
- Certification and achievement wallet
- Internship / job pathway handoff
- Business cybersecurity assessment intake
- Business security service dashboard
- Founder security overview

### Safe training loop

LEARN → PRACTICE IN AUTHORIZED LAB → DEFEND → DETECT → RESPOND → DOCUMENT → SCORE → ACHIEVEMENT → JOB / BUSINESS PATHWAY.

Training environments must be sandboxed or explicitly authorized. Product design must not present unauthorized intrusion as a supported workflow.

### StreetVerse connection

StreetVerse can host fictional/controlled cyber missions such as securing a virtual business, identifying a simulated phishing campaign, restoring a fictional service, protecting a virtual event or operating a training SOC. Mission rewards flow through the same verified XP/reward design system as other StreetVerse missions.

### Business connection

Business Passport → optional cybersecurity readiness assessment → recommendations → permitted security service/training package → service status → Business Ledger.

No interface should claim a business is secure merely because it completed an assessment; results are readiness indicators, not guarantees.

## PropertyVerse — Home Flipping + Property Development

Purpose: connect StreetVerse property gameplay, renovation/design learning and a real-world property project-management pathway while keeping simulated economics separate from real transactions.

### Required Figma pages and frames

- PropertyVerse Home
- Property discovery / map
- Property detail
- Digital twin / walkthrough
- Inspect property
- Rehab scope builder
- Room-by-room renovation planner
- CAD / floor-plan view
- Accessibility retrofit planner
- Materials / fixture selection
- Contractor / service marketplace handoff
- Budget and contingency worksheet
- Before / after visualization
- Flip simulation
- Rental simulation
- Property business dashboard
- Project timeline
- Documents / permits checklist
- Offer / transaction handoff state
- Property ledger
- StreetVerse property ownership / access screen

### PropertyVerse simulation loop

DISCOVER → INSPECT → ESTIMATE → DESIGN → BUDGET → FINANCE SCENARIO → RENOVATE SIMULATION → RE-INSPECT → STAGE → RENT / SELL SCENARIO → PROFIT-AND-LOSS REVIEW.

Estimated value, renovation cost, financing, rent, sale price and profit must be labeled as estimates/simulations until supported by real verified data and professionals.

### StreetVerse property loop

Players can discover virtual properties, enter buildings, inspect rooms, select renovation missions, redesign spaces, complete construction objectives, furnish/stage, operate permitted virtual businesses and rent/sell virtual property according to platform rules.

Real property ownership and virtual property ownership must never be represented as the same legal asset.

### Home-flipping business pathway

Real-world mode can become a project-management and lead marketplace:

PROPERTY LEAD → DUE-DILIGENCE CHECKLIST → INSPECTION → SCOPE → ESTIMATES → FUNDING OPTIONS → CONTRACTORS → PROJECT TRACKING → STAGING → LISTING/RENTAL HANDOFF → VERIFIED ACCOUNTING.

Licensed activities must route to appropriately licensed professionals where required.

## Shared Jacobie Vision + PropertyVerse opportunities

Jacobie Vision can protect PropertyVerse accounts, business profiles, project documents and transaction workflows through security controls. PropertyVerse creates a practical business environment where cybersecurity awareness, identity protection, fraud prevention and secure document handling matter.
