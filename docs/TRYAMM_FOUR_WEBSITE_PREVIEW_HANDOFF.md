## Design rules
- Browser-first, mobile-responsive; keyboard-accessible buttons, readable layout.
- Decorative CSS holographic portal and loading concepts with prefers-reduced-motion fallback.
- No externally loaded Lottie library yet, no full Three.js scene in these sites.
- Demo-only CTAs; no customer personal data collection, verified bookings, payments, AI calls, or production publishing.
- Replace demo content with business-approved media and pricing, contact details, verified legal disclosures and tested intake before publishing.

## Release sequence
1. Review the four visual previews in the conversation package and obtain content/media approvals.
2. Import approved HTML/CSS into this repo under a namespaced route, not production root.
3. Test link navigation, mobile/keyboard usability, page-speed budgets and truthful CTAs.
4. Wire secure per-business lead delivery, booking and payment as separate verified capabilities.
5. Preserve old versions and stage before merge/release.
