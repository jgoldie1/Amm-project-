## Proposed AI Café intake pipeline
1. **Scout:** record exact creator post + screenshot description + publishing date and demo claim. Avoid bulk Instagram scraping or private content extraction.
2. **Resolve:** extract official project repository, docs, active maintenance, model/weight licensing and commercial rights.
3. **Classify:** agent coding, game simulation, asset/Blender, animation, video, voice, social marketing, security, deployment, accessibility.
4. **Security review:** version pin, dependency audit, secret handling, sandbox, no unsigned model downloads or production tokens.
5. **Compatibility:** Node 24, Vite/Three.js, Chromebook/iPhone browser, GPU constraints, existing TRYAMM modules.
6. **Prototype:** isolated feature branch and no-op/default-off adapter; reuse current AI Café, Repair Guardian, Motion Fusion and Film Engine.
7. **Prove:** failing test first, green automated tests, iPhone visual evidence, cost cap, accessibility and rollbacks.
8. **Approve:** human-reviewed PR; production deploy and payments separately authorized.
