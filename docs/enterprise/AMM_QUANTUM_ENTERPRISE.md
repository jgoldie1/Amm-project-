# AMM Quantum Enterprise and Partner Network

## Purpose

AMM Quantum Enterprise extends the existing TryAMM creator platform with reusable organization, partner, subscription-request, audit, and administrative capabilities. It does not replace the existing authentication, creator, music, livestream, gift, or Stripe flows.

## Current implemented slice

- Enterprise command-center web page
- Organization creation and membership roles
- Enterprise plan catalog and sales-review requests
- AMM Partner Network applications
- Partner categories and levels
- Partner lead registration and pipeline value
- Enterprise audit events
- Admin enterprise summary
- Shared TryAMM bearer-token authentication
- Existing JSON persistence adapter reused

## Important gaps before selling to large enterprises

The current repository is an MVP using a local JSON data store. Before high-value contracts, migrate enterprise records to a managed database, add verified email invitations, SSO/SAML, MFA, granular RBAC, tenant isolation tests, billing subscriptions, webhook reconciliation, rate limits, structured logging, backups, disaster recovery, privacy tooling, security reviews, support SLAs and contract workflows.

The Living Worlds runtime remains a separate engineering milestone. It must not be represented as verified until portal transition, budget enforcement and renderer.info memory-release tests pass.
