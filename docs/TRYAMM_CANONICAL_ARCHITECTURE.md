# TRYAMM Canonical Architecture v1

Status: LOCKED BASELINE

## Experience shell
HOME | PLAY | LIVE | CREATE | NEXUS

HOME discovery lanes: For You | Following | New | Local | Global | Faith | Music | Movies | Anime | Games | Learn | Opportunities.

## Algorithm federation
An Algorithm Router selects specialized ranking for discovery, new creators, following, local/global, faith, games/matchmaking, opportunities, talent, Academy, marketplace, music, awards eligibility, safety and accessibility. Algorithm Studio lets people create named/shareable/remixable ranking presets using sliders, rule blocks or natural language. Algorithms control ranking only after eligibility/safety filtering.

## Account + Passport + Wallet
One user ID spans the platform. All American Passport is a TRYAMM membership/achievement/reputation credential, distinct from government identity documents. All American Wallet presents financial state from Money Engine; it is not itself the accounting ledger. Regulated identity, card issuing and tap-to-pay depend on approved external partners.

## Creator Project
A project is a durable creative property containing related assets, collaborators, rights, releases and commerce. Example: one story can produce a film, anime, soundtrack, Reels, game, merchandise, immersive world, LIVE premiere and Omni Box while sharing a versioned rights tree.

## Rights + Money
Rights Registry answers who owns/created an asset, permitted uses/territories/term and contractual splits. Money Engine answers what happened financially. Every posted transaction is double-entry and auditable. Creator/rightsholder liabilities remain separate from TRYAMM revenue. Restricted sponsor/charity/legacy/ministry money remains restricted until valid disposition.

## Creator economy
Academy → Create/Studio → Rights → Publish/Distribution → Discovery → Watch/Listen/Play → Commerce → Money Engine → Wallet/Payout → Charts/Certifications → Nomination/Voting → Awards → Hall of Fame/Legacy.

## Faith + service
Set Apart Music provides a dedicated faith-centered music lane, including Yahuah-centered rap/music, gospel, worship, testimony and spoken word. Faith awards recognize artistic and service impact. Kenosha Stubbs Legacy Award is a living-honor award rooted in compassion, family, community and licensed social-work service.

## Platform foundations
Universal search; notifications/inbox; project collaboration rooms; trust/reputation; content provenance; moderation/safety; globalization; accessibility; analytics; recommendation controls; backups/recovery; admin command center; support; developer platform; observability; policy/legal center; feature-flagged launch control.

## Launch states
DEMO → INTERNAL → ALPHA → BETA → PUBLIC.
Separate switches govern REAL MONEY, REAL PAYOUTS, PRIZE COMPETITIONS, EXTERNAL DISTRIBUTION and regulated identity/card capabilities.

## Completion principle
Freeze unnecessary top-level expansion. Integrate and finish. A capability is not production-ready merely because UI, mock data or a schema exists.
