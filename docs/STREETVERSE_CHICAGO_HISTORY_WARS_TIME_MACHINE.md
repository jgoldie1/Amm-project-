# StreetVerse Chicago History Wars + Time Machine

Status: EXPERIMENTAL / DRAFT PR #251

## What the Time Machine changes

StreetVerse already has a Chicago Time Machine runtime with persistent missions, saved state, Easter eggs, evidence labeling, Chrono experiences, simulated wormhole/warp transitions and a StreetVerse return portal.

Adding historical campaigns turns it into a reusable game engine:

PRESENT CHICAGO
→ TIME MACHINE
→ ERA RECONSTRUCTION
→ EVIDENCE LABEL
→ A/B/C ROLEPLAY CHOICE
→ MISSION
→ ARCHIVE / EASTER EGG
→ RETURN PORTAL
→ PRESENT-DAY UNLOCK.

The player does not alter real history. The historical run changes their fictional present-day StreetVerse through knowledge, bonds, titles, creator assets, mission variants and secrets.

## Campaign: Chicago Kung Fu / Dojo Wars

Historical anchor:
Chicago had intense dojo rivalries in the 1960s and 1970s. John Keehan, later known as Count Dante, was part of that scene. A 1970 conflict involving the Black Dragons and Green Dragons ended with the death of martial artist Jim Koncevic.

Because some details survive through conflicting recollections and martial-arts legend, the Time Machine must label evidence:
- documented;
- mixed;
- recollection;
- legend;
- fictionalized gameplay.

### Route A — ACTION
Safe/nonlethal tournament and training gameplay:
- timing;
- blocking;
- footwork;
- stamina;
- counter windows;
- dojo tournament finale.

### Route B — BUILD / BUSINESS
Run a fictional Chicago dojo:
- rent/training space;
- recruit students;
- class schedule;
- reputation;
- equipment;
- community workshop;
- safe tournament promotion.

### Route C — LEARN / TEST
Historical investigation:
- interview simulated witnesses;
- inspect archive cards;
- compare newspaper/reporting versus later legend;
- classify claims;
- pass evidence-literacy test.

## Campaign: Al Capone / Prohibition Chicago

Historical anchor:
Al Capone rose in Chicago's Prohibition-era organized crime world and became a leading figure after John Torrio withdrew from active control. Capone was ultimately convicted on federal tax charges in 1931.

This mode should show the whole city rather than glamorize one criminal figure:
- working neighborhoods;
- legal businesses;
- newspapers;
- law enforcement;
- reformers;
- nightlife/jazz;
- Prohibition economics;
- bootlegging's social consequences;
- organized-crime violence.

### Route A — ACTION
Fictional evidence-recovery / enforcement scenario.

### Route B — BUILD / BUSINESS
Keep a legitimate neighborhood business alive during economic and social disruption.

### Route C — LEARN / TEST
Research:
- Capone timeline;
- Prohibition;
- press;
- Untouchables;
- documented versus mythologized stories.

## Cross-era Time Machine mystery

The strongest feature is a Chicago Chronokey campaign.

Example:
1920s archive clue
→ 1970 dojo clue
→ 1980s House Music clue
→ 1992 tunnel/flood clue
→ present StreetVerse vertical-city location
→ five-layer secret room.

This makes the city's real history part of exploration rather than a menu.

## Present-day effects

Completing historical campaigns can unlock:
- alternate NPC dialogue;
- historian/heritage neighborhood affinity;
- creator props and filters;
- dojo mentor bond;
- business introductions;
- vintage vehicle liveries;
- Chicago history titles;
- new modern missions;
- hidden rooms;
- multi-era Easter eggs.

## Time Machine + five Chicago layers

History can change which layers are emphasized:
- elevated rail history → Elevated / L layer;
- street businesses / Prohibition → Street layer;
- historic freight and service corridors → Lower layer;
- subway/Pedway history → Underground layer;
- river engineering / waterfront history → River layer.

This gives each vertical layer a past, present and speculative future.

## Source integrity

For real historical people/groups:
- source factual claims;
- label conflicting accounts;
- never manufacture quotations;
- distinguish documentary reconstruction from fictional mission content;
- never convert historical organized crime into real-world crime instruction.

The result should feel cinematic while still teaching players how history is known.
