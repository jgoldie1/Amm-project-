# Unified Account, All American Passport and Wallet

## One identity
Use one canonical TRYAMM user ID across profile, PLAY, LIVE, CREATE, Academy, Marketplace, Creator Studio, Wallet, Passport and Awards.

## Passport
All American Passport is a TRYAMM membership/achievement/reputation credential. It can record Founding Player, creator milestones, Academy credentials, Set Apart achievements, certifications, nominations, awards, service recognition and Hall of Fame history. It is not a government passport.

External government identity/driver-license/passport verification must remain clearly government-issued and use selective disclosure where possible (for example age-verified rather than exposing a full document).

## Wallet
Wallet is a presentation and action layer over Money Engine, not a second ledger. Keep Creator Earnings, Seller Earnings, Prizes/Rewards and Promotional/Game Credits visually/accountingly distinct. Show available, pending, held and paid states with transaction-level explanations.

Regulated card issuing, NFC payment acceptance, money transmission and government credential support require approved partners/compliance before activation.
