# StreetVerse Green Dragon Animal Style System

Status: EXPERIMENTAL / DRAFT PR #251

## Historical integrity

The game contains historically documented Chicago Green Dragon / Black Dragon rivalry material, but the exact animal-style curriculum in this file is treated as **StreetVerse game canon / reconstruction** unless a reliable historical source verifies a specific style.

User-specified Green Dragon core roster:
- Panther
- Leopard
- Boar
- Snake
- Mantis
- Crane
- Eagle
- Tiger
- Dragon

The registry is extensible so additional animal-inspired game styles can be added without rewriting the combat engine.

## What each style does

Each style changes GAMEPLAY STATS rather than teaching real-world injury techniques:
- speed;
- balance;
- reach;
- evasion;
- control;
- power.

Each also receives a one-hand-friendly input pattern and fictional special move.

## Dragon style

Dragon is the mastery / adaptation style.

It acts as the bridge between other Green Dragon forms:
- switching;
- balance;
- context actions;
- broad proficiency.

Dragon mastery can progressively unlock reconstructed extended animal forms.

## One-hand play

Core input vocabulary stays intentionally small:
- TAP
- HOLD
- SWIPE
- FOCUS
- PARRY
- STYLE WHEEL

No required two-button chord.

The one-hand RP controller can emit contextual combat actions, while the martial runtime decides what the selected style means.

## Game progression

Players can progress:
NOVICE → STUDENT → FIGHTER → INSTRUCTOR → MASTER → GRANDMASTER.

Style XP and mastery persist.

Possible rewards:
- dojo titles;
- tournament invitations;
- mentor bonds;
- style-specific emotes;
- creator poses;
- cosmetic uniforms;
- historic lore cards;
- training missions;
- cross-era Time Machine challenges;
- permanent non-pay-to-win style mastery.

## Time Machine use

In the 1970 Chicago Dojo Wars reconstruction:
- Green Dragon animal styles can be selectable as gameplay reconstruction;
- Black Dragon content uses sourced historical inspiration where supported;
- an evidence badge distinguishes documented history from reconstructed game systems.

This makes the Time Machine both entertaining and educational without pretending uncertain details are established historical fact.
