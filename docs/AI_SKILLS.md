# TryAMM AI Skills Catalog

These are application skills, not unrestricted autonomous permissions. Every skill must enforce authentication, authorization, validation, audit logging and user confirmation for sensitive actions.

## Core Skills

### platform_navigator
Explains TryAMM areas and returns safe application routes.

### knowledge_search
Retrieves approved platform, support, faith, accessibility and franchise documents. Returns source IDs with every grounded answer.

### content_discovery
Searches approved shows, episodes, music, podcasts, manga, games and creator channels by genre, age rating, runtime, language and accessibility features.

### creator_coach
Guides profile setup, uploads, metadata, release planning, thumbnails, captions, pricing and promotion. It does not publish without confirmation.

### marketplace_search
Finds products and vendors. It cannot place orders or charge users without an authenticated checkout and explicit confirmation.

### faith_guide
Provides faith-program navigation and approved study material using Yahavah, Yahusha Ha Mashiach and Ruach where relevant. It separates Scripture, history, interpretation and fiction.

### accessibility_guide
Produces voice-first, one-handed, keyboard-friendly instructions with large-control and reduced-motion options.

### nerd_lore
Analyzes original anime, manga, cosplay, gaming and franchise continuity, including character arcs, power systems, timelines, props and costume construction.

### safety_moderator
Classifies spam, harassment, threats, sexual content, exploitation and other policy risks. High-impact enforcement requires policy rules and human review paths.

### feedback_collector
Records thumbs-up/down, reason, mode, source use and response metadata without storing unnecessary private content.

## Tool Safety Levels
- Read-only: may run after authentication when needed.
- Draft-only: creates a reviewable draft but does not publish.
- Confirmed write: requires explicit user confirmation.
- Restricted: payments, payouts, identity, moderation bans and legal actions require dedicated authorization and audit controls.

## Skill Contract
Every skill should define:
1. Purpose
2. Required inputs
3. Authentication level
4. Data sources
5. Allowed actions
6. Disallowed actions
7. Confirmation requirement
8. Error behavior
9. Audit fields
10. Evaluation cases
