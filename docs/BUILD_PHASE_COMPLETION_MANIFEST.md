## Asset completion rule

Every remaining visual, audio, character, vehicle, building, route, animation, world and game asset must enter through the HoloVerse Asset Registry with:

- asset ID and version
- creator and rights owner
- license or permission evidence
- source file and export formats
- age rating and content classification
- accessibility metadata
- language metadata
- world and game compatibility
- performance budgets and level-of-detail variants
- checksum and provenance
- approval, replacement and takedown status

Assets may be added later without redesigning the shared identity, wallet, progression, accessibility, translation, transit, news or archive layers.

## Release truth

The current repository represents a **verified pre-alpha / web-beta foundation**. Production launch still requires genuine evidence for:

- public staging and production deployments
- provider credentials and approved payment pilots
- native Unreal, Unity or Godot builds
- final licensed or original art, music and performed audio
- multiplayer and media infrastructure
- physical controller, AR, VR, MR and holographic-device tests
- accessibility participant testing
- penetration testing and independent security review
- legal, privacy, child-safety, marketplace and country reviews
- app-store, platform and hardware certification

## Freeze decision

New major product categories should not be added during stabilization unless they close a safety, legal, reliability or launch-critical gap. The next phase is testing, deployment, asset production, vertical-slice gameplay and evidence collection.
