## Certification Rule

A community area is marked **COMPLETE** only when all required evidence is present:

1. official boundary/sector mapping
2. streets/navigation
3. playable world geometry
4. buildings
5. businesses and landmarks
6. NPC population
7. vehicles/transit
8. missions/interactions
9. production test

Statuses:

- COMPLETE — all gates passed and production behavior verified
- PARTIAL — some implementation evidence exists, but one or more gates are missing
- MISSING — no area-specific implementation evidence has yet been verified

The current audit does not yet have enough area-specific evidence to certify any individual area COMPLETE. StreetVerse itself has substantial committed implementation; this tracker is specifically for area-by-area Chicago certification.

## Audit Procedure

For each area:

1. Search source and data files for area name, number, slug and geographic identifiers.
2. Record exact repository paths and commit SHAs.
3. Confirm geometry/world assets load.
4. Confirm player spawn/navigation.
5. Confirm buildings/businesses/landmarks.
6. Confirm NPC and traffic/transit behavior.
7. Confirm at least one area-specific interaction/mission where required.
8. Test production route/device coverage.
9. Change overall status only when evidence supports it.

## Priority Build Order

Do not attempt to claim all 77 at once. Use a repeatable district pipeline and certify areas in batches. Prioritize already-developed Chicago content and central/high-visibility areas first, then expand outward while reusing the same world-generation, navigation, business, NPC and mission systems.
