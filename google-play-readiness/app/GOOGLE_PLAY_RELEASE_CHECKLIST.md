# Google Play release checklist

- [ ] Production TryAMM repo connected and integration completed
- [ ] CHILD/TEEN/ADULT permissions enforced server-side
- [ ] Minor/adult messaging and livestream boundaries tested by direct API calls
- [ ] Report/block/mute/moderation fully persisted and audited
- [ ] Account deletion available in-app and on web
- [ ] Privacy Policy, Terms, Community Guidelines, Child/Teen Safety pages live
- [ ] SDK/data inventory matches Play Data Safety form
- [ ] Digital goods billing reviewed for Google Play requirements
- [ ] Physical goods/services payment flows classified separately
- [ ] Reviewer credentials created
- [ ] Android permissions reviewed
- [ ] Production AAB built and signed
- [ ] Closed/internal test completed
- [ ] Content rating and target audience declarations reviewed against shipped behavior
